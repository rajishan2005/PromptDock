PromptDock — Privacy Policy

Last updated: September 2026

PromptDock is a browser extension that adds a PDF viewing, cropping, and question-extraction panel to ChatGPT (chatgpt.com / chat.openai.com). This page explains what data the extension touches and what it does with it.

Summary

PromptDock does not collect, transmit, or sell personal data to PromptDock or its developer. PDF processing and saved local data stay in the browser unless the user explicitly sends content through ChatGPT or chooses to download a question bank from the public question-bank repository.

What data PromptDock handles, and where it stays

  • PDF files you upload are read and rendered entirely in your browser to show the preview, let you crop, and extract question text. If you save a PDF to the library, the file is stored using chrome.storage.local on your device. It is not uploaded to a PromptDock server.
  • Cropped question images are generated locally and inserted into the ChatGPT chat box you are already using. They are not routed through a PromptDock server.
  • Saved chat links store only the ChatGPT conversation URL you explicitly choose to save, plus local PDF context used by the extension. These values are stored locally.
  • Autosolve automates typing and submitting text into ChatGPT's own input box. PromptDock does not send those questions or answers to a PromptDock backend.
  • Question Bank Store reads public file and folder metadata from the PromptDock question-bank repository on GitHub and can download PDFs directly from that public repository when you choose to do so. PromptDock does not upload your personal PDFs or other private data to that repository.

What PromptDock does NOT do

  • It does not operate a backend server for user PDF processing or Autosolve.
  • It does not use analytics, tracking pixels, or third-party advertising SDKs.
  • It does not sell or share user data with advertisers or data brokers.
  • It does not request access to arbitrary websites. Its content script runs only on chatgpt.com and chat.openai.com.

Permissions explained

  • storage / unlimitedStorage — used to save PDFs and saved chat links locally on your device. PDFs can be several megabytes each, which is why the higher storage allowance is requested.
  • Host permission for chatgpt.com / chat.openai.com — required so PromptDock can display its panel and insert content into ChatGPT's chat box on those sites.
  • Limited GitHub host permissions — used only to read the public rajishan2005/pdqb question-bank repository and download question-bank PDFs that you choose from the Store.

Third-party libraries

PromptDock bundles PDF.js, an open-source PDF rendering and parsing library developed by Mozilla. The bundled library is included locally in the extension package and is not loaded from a remote script.

Removing your data

You can delete saved PDFs or chat links directly inside the extension's Library and Saved Chats sections. Uninstalling the extension removes data stored by PromptDock in its extension storage.

Changes to this policy

If this policy changes, the update will be reflected on this page with a new "Last updated" date.
